## 🎮 Featured Project

### Game-Side

Game-Side is a Full Stack web application designed to help gamers discover, organize and rate videogames based on their personal preferences.

The platform allows users to register, log in, explore games, create personalized lists, mark favorites, track their progress, rate titles, leave comments and receive recommendations based on a preference survey.

This project was built using React, React Router, Context API, Python, Flask, SQLAlchemy, PostgreSQL, JWT, Cloudinary and IGDB.
